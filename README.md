### 🔷 E-Commerce Application — End-to-End DevOps Implementation
> `AWS` `Docker` `Kubernetes` `Terraform` `GitHub Actions` `Argo CD`
`Primary Project — 2024–Present`

- Implemented the complete DevOps lifecycle for a microservices-based e-commerce application: containerization, orchestration, IaC, and CI/CD
- Provisioned an EKS cluster inside a custom VPC using Terraform modules, including subnets, security groups, and IAM roles
- Built a full CI/CD pipeline for a Java-based microservice using GitHub Actions (build/test) and Argo CD (GitOps deployment), achieving single-touch end-to-end automation
- Configured AWS networking with VPC, Load Balancers, and Route 53 DNS mapping to securely expose the frontend to external users
- Containerized all microservices with Docker and managed orchestration via Kubernetes (Deployments, Replica Sets, Services, Pods)
